📋 How to connect your Google Sheet in 60 seconds (Click to view simple steps)

1. Open a new Google Sheet at sheets.new. In Row 1, add headers: Timestamp | Name | Email | Message.

2. In Google Sheets, click Extensions $\rightarrow$ Apps Script.

3. Paste this 5-line script and click Save:

function doPost(e) {
  var sheet = SpreadsheetApp.getActiveSpreadsheet().getActiveSheet();
  var data = JSON.parse(e.postData.contents);
  sheet.appendRow([data.timestamp, data.name, data.email, data.message]);
  return ContentService.createTextOutput(JSON.stringify({"result":"success"})).setMimeType(ContentService.MimeType.JSON);
}

4. Click Deploy $\rightarrow$ New Deployment $\rightarrow$ Select type Web App $\rightarrow$ Set "Who has access" to "Anyone" $\rightarrow$ Click Deploy.

5. Copy the Web App URL and paste it into the input box above!
